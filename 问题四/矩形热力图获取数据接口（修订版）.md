## 📊 矩形热力图获取数据接口（修订版）

### 接口信息

- **接口地址**: `GET /api/charts/heatmap/city-tier`
- **功能描述**: 获取不同城市等级分类的热力图数据，基于实际数据库字段

------

### 请求参数

| 参数名        | 类型   | 必填 | 说明                                                         |
| :------------ | :----- | :--- | :----------------------------------------------------------- |
| `tier`        | string | 是   | 城市等级，可选值：`first_tier`(一线), `second_tier`(二线), `third_tier`(三线), `other`(其他) |
| `dimension_y` | string | 否   | Y轴维度，默认：`company_type`（公司类型）                    |
| `metric`      | string | 否   |                                                              |

------

## 响应字段说明

### data 对

| 字段名                              | 类型     | 说明                          |
| :---------------------------------- | :------- | :---------------------------- |
| `tier`                              | string   | 请求的城市等级类型            |
| `tier_name`                         | string   | 城市等级中文名称              |
| `city_count`                        | number   | 该等级下的城市数量            |
| `dimensions`                        | object   | 热力图的维度信息              |
| `dimensions.x_axis`                 | string[] | X轴维度值列表（城市名称）     |
| `dimensions.y_axis`                 | string[] | Y轴维度值列表（公司类型编码） |
| `heatmap_data`                      | object[] | 热力图数据点列表              |
| `heatmap_data[].x`                  | string   | X轴对应值（城市名称）         |
| `heatmap_data[].y`                  | string   | Y轴对应值（公司类型编码）     |
| `heatmap_data[].value`              | number   | 热力值（度量字段的数值）      |
| `heatmap_data[].count`              | number   | 该组合下的职位数量            |
| `heatmap_data[].detail_info`        | object   | 悬浮提示详细信息              |
| `detail_info.industry_ratio`        | number   | 该类型在城市中的占比          |
| `detail_info.location_quotient`     | number   | 区位商，衡量产业专业化程度    |
| `detail_info.avg_education_rank`    | number   | 平均学历要求分数              |
| `detail_info.avg_experience_rank`   | number   | 平均经验要求分数              |
| `detail_info.company_count_in_city` | number   | 该城市的所有公司数量          |
| `detail_info.national_job_count`    | number   | 全国范围内该类型的职位总数    |
| `metric`                            | string   | 当前使用的度量字段            |
| `title`                             | string   | 热力图标题                    |

------

### 可用度量字段说明

| metric              | 说明                 | 数据来源                              |
| :------------------ | :------------------- | :------------------------------------ |
| `job_count`         | 职位数量             | `city_type_statics.job_count`         |
| `industry_ratio`    | 行业占比             | `city_type_statics.industry_ratio`    |
| `location_quotient` | 区位商（专业化程度） | `city_type_statics.location_quotient` |

------

### 使用示例

#### 获取一线城市职位数量热力图：

```
GET /api/charts/heatmap/city-tier?tier=first_tier&metric=job_count


```

#### 获取二线城市行业占比热力图：

```
GET /api/charts/heatmap/city-tier?tier=second_tier&metric=industry_ratio
```

#### 获取三线城市区位商热力图：

```
GET /api/charts/heatmap/city-tier?tier=third_tier&metric=location_quotient
```

------

### 前端悬浮提示使用：

当用户将鼠标悬停在热力图的某个矩形块上时，可以使用 `detail_info` 中的字段显示基本信息：

```

公司类型：type_lOdYUb
职位数量：28,500
行业占比：35%
区位商：1.8
平均学历：3.8/5.0
平均经验：2.5年
公司数量：1,250
全国同类职位：158,000
```

------

### 数据说明

1. **Y轴维度**：默认为公司类型编码（`company_type`），每个城市只展示前20的公司类型，其余归为"其他"
2. **"其他"类别处理**：`location_quotient` 为0，在热力图中会显示为特殊颜色
3. **数据范围**：每个城市最多21条记录（20个具体类型 + 1个"其他"类别）

### 错误处理

- 如果 `tier` 参数不在可选范围内，返回400错误：

```json
{
  "code": 400,
  "message": "tier参数错误，可选值：first_tier, second_tier, third_tier, other",
  "status": "error",
  "timestamp": "2025-10-27T23:45:30.987654"
}
```
